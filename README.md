# 🗄️ Реляционная база данных для E-Commerce (Магазин посуды)
Учебный проект по проектированию и разработке реляционной базы данных SQL для интернет-магазина кухонной посуды и аксессуаров.
### 📌 Архитектура базы данных
База данных содержит следующие связанные таблицы:
* **`Categories`** - категории товаров (кастрюли, сервировка, утварь).
* **`Products`** - каталог товаров с ценами, остатками и внешними ключами на категории.
* **`Customers`** - учетная запись покупателей.
### 🚀 Использованные технологии и навыки
* **Язык:** SQL (MySQL / PostgreSQL / SQL Server).
* **Команды DDL:** `CREATE TABLE`, первичные (`PRIMARY KEY`) и внешние ключи (`FOREIGN KEY`).
* **Команды DML:** `INSERT INTO` для наполнения тестовыми данными.
* **Запросы:** `SELECT`, объединение таблиц через `JOIN`.
### 📂 Файлы в проекте
* `schema.sql` - полный SQL-скрипт для создания структуры, заполнения данными и проведения выборок.
